💬 Комментарий учителя:

Перед тренировкой: что ставим после какого глагола. Каждый правильный ответ дальше = +1 karma.

⚠️ Ловушки:
like / love / prefer + doing, но would like / would love / would prefer + to do
stop doing = перестать делать · stop to do = остановиться, чтобы сделать
make / let / help + кого-то + глагол без to: I will make you cry

Выбери правильную форму в каждом пропуске и нажми «Проверить». Глагол-подсказка выделен жёлтым.

Комментаторы на Reddit пишут быстро и с ошибками. Решай: всё правильно или есть ошибка?
